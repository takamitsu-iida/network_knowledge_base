# ネットワーク採番・設計ポリシー (Addressing & Numbering Policy)

本ドキュメントは、組織内のネットワーク設計における採番基準を定義する。
自動設計やAIによる設定生成を行う際は、本ポリシーに従うこと。

## 1. Loopback IP 設計ルール

全てのルータ・スイッチにおいて、以下のインターフェースを定義する。

- **Loopback0 (Router ID / BGP Peering):**
  - アドレス範囲: `192.168.255.0/24`
  - 割当単位: 機器ごとに /32 を固定割り当て。
  - ルール: 昇順で割り当てる。

VXLAN VTEPを動作させる装置において、以下のインタフェースを定義する。

- **Loopback1 (VTEP Source IP):**
  - アドレス範囲: `192.168.254.0/24`
  - 割当単位: 機器ごとに /32 を固定割り当て。
  - ルール: Loopback0 と同じホストID番号を使用すること。

## 2. VNI (VXLAN Network Identifier) 設計ルール

VNI は L2VNI と L3VNI に分類し、以下の範囲で定義する。

- **L2VNI (Layer 2 Segmentation):**
  - 範囲: `10000` ～ `19999`
  - 計算式: `10000 + VLAN ID`
  - 例: VLAN 10 = VNI 10010

- **L3VNI (VRF/L3 Segmentation):**
  - 範囲: `50000` ～ `59999`
  - 計算式: `50000 + VRF ID`

## 3. BGP AS番号設計

- **Fabric AS (Internal):** `65000`
- **使用範囲:** 全 Fabric 内デバイスは同一の AS 番号を使用する (iBGP 構成)。

## 4. ESI (Ethernet Segment Identifier) 採番ルール

ESI-LAG 構成における ESI 値は、以下のフォーマットで記述する。

- **フォーマット:** `00:00:5e:00:01:XX:XX:XX:XX:YY`
  - `XX:XX:XX:XX`: サイト・フロア識別子 (組織標準)
  - `YY`: 冗長ペア内のリンクID (例: 01, 02...)

- **制約:** 冗長ペア内で同一の ESI を使用すること。

## 5. BGP EVPN Route Target (RT)

- **RT 形式:** `AS番号:VNI`
- **ルール:** Import/Export は原則として対称（同一値）とする。
- **例:** `65000:10010`

---

## 運用上の注意 (AIによる生成用)
AIが本ドキュメントを基にパラメータを決定する際は、以下のステップを踏むこと。

1. **重複確認:** 既存の設計ファイル (`03_projects/`) をスキャンし、割り当て済みの IP/VNI がないか確認する。
2. **計算:** 本ポリシーの計算式に従い、自動的に採番を行う。
3. **整合性チェック:** 生成された値が他の要件（MTU, セグメント設計など）と矛盾しないか確認する。
